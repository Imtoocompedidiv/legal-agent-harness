La banque fait grief à l'arrêt de la condamner à payer à la société une certaine somme à titre de dommages et intérêts, alors « que dès lors que la responsabilité d'un prestataire de services de paiement est recherchée en raison d'une opération de paiement relevant des articles [L. 133-1 et suivants](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-1/2025-06-12) (+ [L133-1-1 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-1-1/2025-06-12), [L133-2 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-2/2025-06-12), [L133-3 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-3/2025-06-12), [L133-4 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-4/2025-06-12), [L133-5 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-5/2025-06-12)) du code monétaire et financier, qui transposent la [directive 2015/2366](https://librejustice.fr/norm/eu/directive-ue-2015-2366-du-parlement-europeen-et-du-conseil-du-25-novembre-2015) du 25 novembre 2015 concernant les services de paiement dans le marché intérieur, seul est applicable le régime de responsabilité défini aux articles [L. 133-18 et suivants](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-18/2025-06-12) du code monétaire et financier, à l'exclusion de tout régime alternatif de responsabilité résultant du droit national ; qu'en l'espèce, après avoir considéré que les opérations litigieuses avaient été dûment autorisées par la société, de sorte que la demande fondée sur les articles [L. 133-18](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-18/2025-06-12) et [L. 133-23](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-23/2025-06-12) du code monétaire et financier ne pouvait être accueillie, la cour d'appel a énoncé qu'il restait à déterminer si la banque n'avait pas néanmoins manqué à son devoir de vigilance au vu des circonstances et que le fait d'avoir exécuté des ordres de virement transmis par le système télématique, formellement réguliers, reçus au travers d'une relation sécurisée destiné à éviter les risques de fraude, ne l'exonérait pas de toute responsabilité, et a considéré que la banque avait manqué à son devoir de vigilance ; qu'en statuant ainsi, la cour d'appel a violé l'article [1147](https://librejustice.fr/norm/fr/code-civil/1147/2025-06-12), devenu [1231-1](https://librejustice.fr/norm/fr/code-civil/1231-1/2025-06-12), du code civil, ensemble les articles [L. 133-18 à L. 133-24](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-18/2025-06-12) (+ [L. 133-19 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-19/2025-06-12), [L. 133-20 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-20/2025-06-12), [L. 133-21 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-21/2025-06-12), [L. 133-22 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-22/2025-06-12), [L. 133-22-1 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-22-1/2025-06-12), [L. 133-22-2 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-22-2/2025-06-12), [L. 133-23 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-23/2025-06-12), [L. 133-23-1 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-23-1/2025-06-12), [L. 133-24 — Code monétaire et financier](https://librejustice.fr/norm/fr/code-monetaire-et-financier/l133-24/2025-06-12)) du code monétaire et financier, dans leur rédaction postérieure à la transposition de la [directive 2015/2366](https://librejustice.fr/norm/eu/directive-ue-2015-2366-du-parlement-europeen-et-du-conseil-du-25-novembre-2015) du 25 novembre 2015. »
